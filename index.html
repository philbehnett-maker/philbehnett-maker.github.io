Quick Start

Get Moose running on your machine. Requires Python 3.11+, Node 18+, and an LLM backend.

1

Clone the repository

git clone https://github.com/moosefinch/moose.git
cd moose
2

Run the setup wizard

cd scripts
python setup.py

Auto-detects your LLM backend and configures everything.

3

Install dependencies & start

cd backend
pip install -r requirements.txt
./start.sh
4

Open the UI

http://localhost:3000

Docker Alternative

cp profile.yaml.example profile.yaml
# Edit profile.yaml with your LLM backend settings
docker compose up --build

About

The person behind Moose

🦌

Finch Behnett

Creator of Moose

I'm a maker and engineer based in Virginia's Shenandoah Valley. I built Moose because I wanted an AI assistant that actually understands the tools I use every day — 3D printers, CAD software, microcontrollers — without sending my projects to someone else's servers.

I'm also the founder of FAESR.ai (Foundation for AI Ethics & Safety Research), a nonprofit focused on open source intelligence and making complex technical systems understandable to the public. The same principles drive both projects: transparency, local-first computing, and putting control back in users' hands.

When I'm not coding, you'll find me designing parts in Blender, running prints on my Bambu Lab, or figuring out why my latest Arduino project isn't working.
