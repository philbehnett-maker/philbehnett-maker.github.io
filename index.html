Quick Start

Get Moose running in minutes. Requires Python 3.11+, Node 18+, and an LLM backend.

1

Clone the repository

git clone https://github.com/moosefinch/moose.git
cd moose
2

Run the setup wizard

cd scripts
python setup.py

Auto-detects LLM backends, generates profile.yaml, and creates a launch daemon.

3

Install dependencies & start

cd backend
pip install -r requirements.txt
./start.sh
4

Open the UI

http://localhost:3000

Docker Alternative

cp profile.yaml.example profile.yaml
# Edit profile.yaml with your LLM backend settings
docker compose up --build
